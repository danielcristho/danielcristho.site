Renaming a resource used to mean a manual `terraform state mv` on every machine and every CI runner. Since 1.1 the rename lives in the code:

```hcl
moved {
  from = aws_instance.web
  to   = aws_instance.api
}
```

`terraform plan` then reports a move rather than a destroy/create, and the block is safe to delete once the change is applied everywhere. Works for modules too (`from = module.old`), which is the real win when splitting a monolith module.
