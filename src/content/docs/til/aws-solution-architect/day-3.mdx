## Network Connectivity

| Service              | What it is                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| Transit Gateway      | Hub and spoke router for many VPCs and on-premises networks. Multiple route tables segment the flows. |
| AWS Network Firewall | Managed firewall for deep packet inspection of traffic between VPCs and to the internet.              |
| VPC peering          | One to one links. Ten VPCs need a mesh, and peering does no inspection.                               |

Route tables are the part worth remembering. Full reach for some VPCs and partial reach for others is one Transit Gateway with two route tables, not two designs.

## Database Storage

`General Purpose SSD (gp3)` includes 3,000 IOPS at no extra cost, and that baseline does not depend on volume size. A database asking for 1,000 IOPS on 40 GiB is already covered by the smallest practical gp3 volume.

| Option                 | Cost for 40 GiB and 1,000 IOPS                                   |
| ---------------------- | ---------------------------------------------------------------- |
| gp3, 50 GiB            | Cheapest. The 3,000 IOPS baseline is included.                   |
| gp2                    | IOPS scale with size, so small volumes buy capacity to get IOPS. |
| Provisioned IOPS (io1) | Pays for IOPS that gp3 already includes.                         |

## Cross-Account Access

A security team with its own account needs to read production settings during audits.

| Step               | What it does                                                      |
| ------------------ | ----------------------------------------------------------------- |
| IAM role           | Created in the production account, holding only read permissions. |
| Permissions policy | States what the auditors can see.                                 |
| Trust policy       | Names the security team account as allowed to assume the role.    |

The team then assumes the role. No IAM users in the production account, and no access keys passed between teams.

## Disaster Recovery

`Pilot light` means the environment exists but is switched off. EC2 instances are built in an AWS Region and stopped. On failure they start and take all traffic.

- RPO and RTO -> tens of minutes.
- Cost -> low, because almost nothing runs until a test or a real failover.
- Recovery -> simple, because the core infrastructure is already in place.

:::note
Pilot light keeps the parts and turns them off. Warm standby keeps a smaller copy running. Backup and restore keeps nothing but the data.
:::

## Temporary Storage

`Instance store` is local disk on the host. It disappears when the instance stops, which is a problem for data you keep and a non-issue for data you discard.

Storage optimized instances are built for high, sequential read and write access to large local datasets, and they deliver tens of thousands of low latency random IOPS. For 400 GB of scratch space at 40,000 random IOPS, the instance store comes with the instance and costs nothing more.
