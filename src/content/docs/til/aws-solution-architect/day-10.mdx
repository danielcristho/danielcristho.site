## EC2

EC2 is Elastic Compute Cloud. It is IaaS: AWS gives you the server, you manage what runs on it.

EC2 is more than virtual machines. It covers:

- Renting virtual machines (EC2)
- Storing data on virtual drives (EBS)
- Spreading load across machines (ELB)
- Scaling with an Auto Scaling Group (ASG)

## What You Configure

| Option      | Choices                                                         |
| ----------- | --------------------------------------------------------------- |
| OS          | Linux, Windows, macOS                                           |
| CPU and RAM | Picked by the instance type                                     |
| Storage     | Network storage (EBS, EFS) or hardware storage (instance store) |
| Network     | Network card speed, public IP                                   |
| Firewall    | Security group                                                  |
| Bootstrap   | User data                                                       |

## User Data

User data is a script that runs at the first boot of the instance. It runs once, as root.

Use it to:

- Install updates
- Install software
- Download files from the internet

## Instance Types

The name tells you what you get. Take `t2.xlarge`:

- `T`: instance class
- `2`: generation
- `xlarge`: size. A bigger size means more CPU and RAM.

| Family            | Classes | Fits                                                                  |
| ----------------- | ------- | --------------------------------------------------------------------- |
| General purpose   | T, M    | Web servers, code repositories. A balance of CPU, RAM, network.       |
| Compute optimized | C       | Batch jobs, media encoding, HPC, game servers                         |
| Memory optimized  | R, X    | In-memory databases, real time big data                               |
| Storage optimized | I, D, H | OLTP databases, data warehouses, high read and write on local storage |
| Accelerated       | P, G    | Machine learning, graphics                                            |

[Amazon EC2 Pricing](https://aws.amazon.com/ec2/pricing) lists every type with its price.
