`Batch Mining`: Processes a finite dataset that has been collected and stored, often through multiple passes.

`Stream Mining`: Processes continuously arriving data under latency and memory constraints.

`Online Learning vs. Stream Mining`: Online learning updates models incrementally, while stream mining also covers monitoring, querying, summarization, and pattern detection.

:::note
Streaming is not just large-scale batch processing. Time, data ordering, latency, and changing data distributions are first-class concerns.
:::

## Design Tension

A streaming system must balance three goals:

| Goal                   | What it demands                                                       |
| ---------------------- | --------------------------------------------------------------------- |
| **Detect quickly**     | Identify patterns or anomalies with minimal delay.                    |
| **Adapt safely**       | Respond to changing data distributions without overreacting to noise. |
| **Stay within budget** | Operate within latency, memory, and computational constraints.        |
