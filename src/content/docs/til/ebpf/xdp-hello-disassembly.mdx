The eBPF part of [Hello XDP](https://aya-rs.dev/book/start/hello-xdp.html) from the aya book does two things:

```rust
fn try_xdp_hello(ctx: XdpContext) -> Result<u32, u32> {
    info!(&ctx, "received a packet");
    Ok(xdp_action::XDP_PASS)
}
```

To see the compiled output:

```sh
llvm-objdump -S target/debug/build/xdp-hello-*/out/xdp-hello
```

## Sections

| Section | Instructions | Contents                                        |
| ------- | ------------ | ----------------------------------------------- |
| `xdp`   | 287          | `xdp_hello`                                     |
| `.text` | 76           | `memcpy`, `memmove`, `memset`, `memcmp`, `bcmp` |

`Ok(XDP_PASS)` is about 2 instructions. The log line is the other 285.

## What The Log Line Does

The kernel has no `printf`. To send a text to userspace, the program:

1. Checks the log level. The check runs on every call. The compiler keeps it.
2. Asks the ring buffer for space.
3. Copies the text in, one byte at a time.
4. Picks a size from a list of fixed sizes. The size must be a constant.
5. Sends the record, or drops it if step 2 failed.

Steps 2 and 5 are kernel helper calls. In the dump they are numbers:

```
16: 85 00 00 00 83 00 00 00    call 0x83
```

`0x83`, `0x84` and `0x85` are helpers 131, 132 and 133: reserve, submit, discard.

The level check is at the top and jumps over the rest:

```
3: b7 02 00 00 03 00 00 00    r2 = 0x3
4: 2d 12 09 01 00 00 00 00    if r2 > r1 goto +0x109
```

`0x109` skips 265 instructions.

## Cost Per Packet

XDP runs on every incoming packet, so the 287 instructions run per packet.

That is fine for learning. For a long running program, use a counter in a map instead of a log. A counter is one or two instructions.

## memcpy

There is no C library, so the compiler generates these functions. Each copies one byte per loop:

```
6: 71 00 00 00 00 00 00 00    w0 = *(u8 *)(r0 + 0x0)
7: 73 05 00 00 00 00 00 00    *(u8 *)(r5 + 0x0) = w0
8: 07 04 00 00 01 00 00 00    r4 += 0x1
9: 2d 43 f8 ff 00 00 00 00    if r3 > r4 goto -0x8
```

Five functions, 76 instructions, all generated.

## Notes

- `llvm-objdump -S` prints each Rust line above the instructions it produced. This makes it possible to trace an instruction back to the source.
- The license section is required:

```rust
#[unsafe(link_section = "license")]
#[unsafe(no_mangle)]
static LICENSE: [u8; 13] = *b"Dual MIT/GPL\0";
```

Some kernel helpers need a GPL compatible license.

These numbers come from one debug build with one log line. A release build or a different log call will give different numbers.
